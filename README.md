# プロジェクト名
hajimete_sns（ちょるのったー）

## 概要
このプロジェクトは、Twitter風の簡易SNSアプリです。  
投稿の作成・編集・削除、ユーザー登録、プロフィール編集など、  
基本的なSNS機能を一通り実装することを目標に開発しました。

学習のアウトプットとしてだけではなく、  
「自分で考えて設計し、形にする力」を養うために制作しました。

## 主な機能
- ユーザー登録 / ログイン機能（認証）
- 投稿の作成、編集、削除
- 投稿一覧表示・詳細表示
- プロフィール編集（名前・アイコン等）
- アカウント作成後の個別ページ機能
- Bladeテンプレートを用いたUI構築

## 使用技術
- Laravel 10
- PHP
- MySQL
- HTML / CSS
- JavaScript

## インストール方法
1. このリポジトリをクローン  
2. `composer install`  
3. `.env` を作成し、データベース設定を記入  
4. `php artisan migrate`  
5. `php artisan serve` で起動
